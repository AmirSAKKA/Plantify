Add a Google Maps key

The map is only used to trace the plot. The finished sheet is the outline and its measurements.

  1. In Google Cloud, enable the Maps JavaScript API and create a key.
  2. Save this as .env in the project folder, then restart the dev server. 
VITE_GOOGLE_MAPS_API_KEY=your_key_here
